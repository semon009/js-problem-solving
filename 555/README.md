# Check Data Type of 555

## Problem Description
Using the `typeof` operator, output the data type of the value `555` to the console.

### Expected Output
```text
number

```

---

## Solution Code

```javascript
let Five_Hundred_Fifty_Five = 555;
console.log(typeof(Five_Hundred_Fifty_Five));
```

---

## Code Explanation

1. **`let Five_Hundred_Fifty_Five = 555;`**: Declares a variable named `Five_Hundred_Fifty_Five` and assigns it the numeric value `555`.
2. **`typeof(Five_Hundred_Fifty_Five)`**: The `typeof` operator evaluates the data type of the value stored in `Five_Hundred_Fifty_Five`, returning `"number"`.
3. **`console.log()`**: Prints the returned type (`number`) to the console.

> **Alternative Direct Solution:** You can also pass the value directly without creating a variable: `console.log(typeof 555);`
