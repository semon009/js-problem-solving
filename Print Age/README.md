# Print Age

## Problem Description
Print the number corresponding to your age in the console.

---

## Solution Code

```javascript
let age = 9942394959239693;
console.log(age);
```

> **Note:** You can also use `const` (`const age = ...`) if the age value is fixed in your program.

---

## Code Explanation

1. **`let age = 9942394959239693;`**: Declares a variable named `age` and assigns it a numeric value.
2. **`console.log(age);`**: Outputs the value stored inside the `age` variable directly to the console.
