# Create Big Number Variable

## Problem Description
Create the `bigNumber` variable and set its value to `9999`.

---

## Solution Code

```javascript
const bigNumber = 9999;
```

```javascript
let bigNumber = 9999;
```

---

> **Note:** Using `let` is also valid (`let bigNumber = 9999;`) if you intend to modify the value later in your program.

---

## Code Explanation

1. **`const bigNumber`**: Declares a block-scoped variable named `bigNumber` using `const`.
2. **`= 9999;`**: Assigns the integer numeric value `9999` to the variable. Numbers in JavaScript are written directly without quotation marks.
