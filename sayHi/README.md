# Say Hi Function

## Problem Description
Create the `sayHi` function that outputs `"Hello"` to the console when called.

### Expected Output
```text
Hello

```

---

## Solution Code

```javascript
function sayHi() {
  console.log("Hello");
}

```

---

## Code Explanation

1. **`function sayHi()`**: Declares a named function `sayHi` that takes no arguments.
2. **`console.log("Hello");`**: Executes the standard JavaScript method to output the string `"Hello"` to the console inside the function body.
