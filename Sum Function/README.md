# Sum Function

## Problem Description
Create the `sum` function that takes two numbers as parameters and returns their sum.

### Sample Usage
```javascript
console.log(sum(3, 5));  // Outputs: 8
console.log(sum(10, 20)); // Outputs: 30

```

---

## Solution Code

```javascript
function sum(x, y) {
  return x + y;
}

```

---

## Code Explanation

1. **`function sum(x, y)`**: Declares a function named `sum` that accepts two parameters, `x` and `y`.
2. **`x + y`**: Uses the addition operator (`+`) to add the two values together.
3. **`return`**: Sends the calculated result back to the caller instead of printing it directly.
