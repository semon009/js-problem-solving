# Create and Log Name Variable

## Problem Description
Create a variable `name` with your name and log it to the console. The name should start with a capital Latin letter.

---

## Solution Code

```javascript
const name = "Wpizza67676767";
console.log(name);
```

---

## Code Explanation

1. **`const name = "Wpizza67676767";`**: Declares a constant variable named `name` assigned to a string value. The string begins with an uppercase Latin letter (`'W'`).
2. **`console.log(name);`**: Outputs the value stored inside the `name` variable to the console.
