# Create Robot Object

## Problem Description
Create an object named `robot` with the following properties:
* `model` with the value `"RX9000"`
* `year` with the value `2024`
* `canDance` with the value `true`

### Expected Output
```text
RX9000
2024
true

```

---

## Solution Code

```javascript
let robot = {
  model: "RX9000",
  year: 2024,
  canDance: true
};

```

---

## Code Explanation

1. **`let robot = { ... };`**: Declares an object literal assigned to the variable `robot`.
2. **`model: "RX9000"`**: Defines the key `model` with a string value `"RX9000"`.
3. **`year: 2024`**: Defines the key `year` with a numeric value `2024`.
4. **`canDance: true`**: Defines the key `canDance` with a boolean value `true`.
