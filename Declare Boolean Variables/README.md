# Declare Boolean Variables

## Problem Description
Declare a variable called `bool1` and set its value to `true`. Then, declare a second variable named `bool2` and set its value to `false`.

---

## Solution Code

```javascript
let bool1 = true;
let bool2 = false;

```

---

## Code Explanation

1. **`let bool1 = true;`**: Declares a variable named `bool1` using `let` and assigns it the boolean literal value `true`.
2. **`let bool2 = false;`**: Declares a variable named `bool2` using `let` and assigns it the boolean literal value `false`.
3. **Boolean Data Type**: Booleans represent logical values that can only be either `true` or `false`.
