# Return Number Function

## Problem Description
Create the `returnNumber` function that takes a number as a parameter and returns it directly.

---

## Solution Code

```javascript
function returnNumber(x) {
  return x;
}

```

---

## Code Explanation

1. **`function returnNumber(x)`**: Declares a function named `returnNumber` that accepts a single parameter `x`.
2. **`return x;`**: Returns the exact value passed into parameter `x` back to the caller.
