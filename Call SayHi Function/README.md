# Call SayHi Function

## Problem Description
Let's strengthen what you've learned and call the `sayHi` function so that it prints `"Hello"` to the console.

### Expected Output
```text
Hello

```

---

## Solution Code

```javascript
function sayHi() {
  console.log("Hello");
}

// Call the function
sayHi();
```

---

## Code Explanation

1. **`function sayHi() { ... }`**: Defines a function named `sayHi` that encapsulates a `console.log("Hello");` statement. Declaring a function creates the blueprint, but does not execute the code inside it automatically.
2. **`sayHi();`**: Invokes (calls) the `sayHi` function using parentheses `()`. This triggers the code block inside the function body, printing `"Hello"` to the console.
